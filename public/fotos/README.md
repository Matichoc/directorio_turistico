# Fotos de lugares

Carpeta para pegar fotos reales descargadas (o tomadas) de cada lugar. Cada
subcarpeta corresponde a un lugar del catálogo. Cuando agregues fotos acá y
avises, se conectan a la ficha correspondiente en `scripts/seed.ts`
(`place_images`, ver `docs/PLAN.md` Riesgos #14).

## Cómo agregar una foto

1. Descarga o copia la imagen (jpg/png/webp; lo ideal es horizontal o
   cuadrada, no muy pesada — unos pocos MB está bien, no hace falta 4K).
2. Pégala dentro de la subcarpeta que corresponda (ver tabla abajo). El
   nombre del archivo no importa, pero evita espacios raros o acentos si
   puedes (ej: `plaza-1.jpg` mejor que `Plaza de Armas (1).jpg`).
3. Si quieres más de una foto por lugar, pega varias — se usa la primera
   que exista, pero puede armarse una galería más adelante.
4. Avísame (en el chat) que ya las subiste y las conecto.

la foto se conecta directo. Las marcadas "○ lugar nuevo" todavía no están
creadas como lugar: además de la foto, en algún momento voy a necesitar
coordenadas GPS (o al menos el nombre del sector/dirección) para poder
crearlas — puedes pasármelas cuando quieras, no hace falta que sea ahora.
